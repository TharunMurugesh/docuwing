# docuwing

Transform unstructured documents into structured, actionable knowledge.

## Current implementation

All roadmap phases 0–15 are represented: engine ingestion through outputs/RAG/workflow maturity; an authenticated FastAPI project/document/schema/review API; and the corresponding Next.js workspace views.

For a local UI demo, sign in with `demo@docuwing.local` / `demo`. The default API service is intentionally in-memory, while database adapters and model transports remain injectable for deployment.
